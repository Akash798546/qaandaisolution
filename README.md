# QA Automation & AI Solutions — Portfolio Starter

A responsive React + Vite portfolio starter for QA automation, AI workflow automation, web scraping and web development services.

## Requirements
- Node.js 18+ (Node.js 20 LTS recommended)
- npm
- Git

## Run locally
```bash
npm install
npm run dev
```
Open the local URL printed by Vite.

## Production build
```bash
npm run build
npm run preview
```

## Important before publishing
1. Replace `YOUR_EMAIL@example.com` with a professional email address.
2. Replace generic profile links with your real GitHub and freelance profiles.
3. Verify every experience duration and skill claim in the About section.
4. Add links to real repositories and screenshots for completed projects.
5. The assistant is currently a guided UI demo, not connected to an LLM.
6. The contact form currently displays a demo notice and does not transmit or store submissions. Connect a secure form backend or form provider before production.
7. The Make.com/n8n and scraping cards are project descriptions, not live integrations. Build and test those workflows before claiming them as delivered services.

## Suggested deployment
- Push the repository to GitHub.
- Import the repository into Vercel or Netlify.
- Build command: `npm run build`
- Output directory: `dist`
